# **App Name**: QuechuaQuick

## Core Features:

- Phrase Display: Display essential Quechua phrases with pronunciation guides and translations.
- Audio Pronunciation: Play audio clips of native speakers pronouncing each phrase.
- Contextual Filtering: Filter phrases by context (greetings, food, shopping, courtesy).
- Andean Music: Display a curated selection of Andean music videos to immerse users in the culture.

## Style Guidelines:

- Primary color: Deep blue (#2C3E50) for titles and borders, conveying professionalism.
- Background color: Pure white (#FFFFFF) to create a clean and modern feel.
- Accent color: Vibrant turquoise (#1ABC9C) for interactive elements such as buttons.
- Secondary color: Soft lilac (#9B59B6) for subtle details and separators.
- Text color: Dark gray (#2C3E50) for important text, medium gray (#7F8C8D) for secondary text.
- Main font: 'Poppins' (sans-serif) for a modern, legible, and mobile-friendly design. Note: currently only Google Fonts are supported.
- Font weights: Light (300) for body text, Semi-bold (600) for titles, Bold (700) for Quechua text. Note: currently only Google Fonts are supported.
- Use simple, clear icons to represent different categories and actions.
- Subtle animations such as fade-in effects, card elevation on hover, and audio wave animations for a premium feel.
